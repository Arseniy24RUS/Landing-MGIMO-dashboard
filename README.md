# Landing page (GitHub Pages)

1) Положите содержимое папки в корень репозитория GitHub (ветка `main` или `gh-pages`).
2) В `index.html` в блоке `Настройки` задайте:
   - `DASHBOARD_URL` — ссылка на опубликованный дашборд
   - `REPO_URL` — ссылка на репозиторий проекта (опционально)
3) В настройках репозитория включите GitHub Pages (Source: `Deploy from a branch`, Folder: `/`).

Структура:
- `index.html` — основной лендинг (SPA-навигация по вкладкам)
- `assets/` — скриншоты страниц дашборда
