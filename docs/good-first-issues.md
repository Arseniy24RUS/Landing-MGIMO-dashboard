# Good First Issues

These starter tasks are suitable for contributors who want to help without changing the main dashboard logic.

## English

1. Verify Markdown image paths
   Check every local image referenced in Markdown files and report or fix missing paths.

2. Add a Markdown link check script
   Create a small local check for repository-relative Markdown links and wire it into `package.json` if maintainers approve.

3. Improve assignment rubrics
   Add concise assessment criteria for widget-level tasks in `docs/methodology.md`.

4. Reconcile visualization counts
   Compare the README, landing page and latest dashboard workbook references to determine whether the correct count is 116 or 117.

5. Update third-party notices
   Review `assets/logos/` and screenshot-like assets, then add any missing third-party notice details.

6. Review bilingual terminology
   Check that English/Russian terms for pages, widgets and assignments are consistent across README, methodology and locale files.

## Русский

1. Проверить пути к изображениям в Markdown
   Найдите все локальные изображения, указанные в Markdown-файлах, и исправьте или зафиксируйте отсутствующие пути.

2. Добавить проверку Markdown-ссылок
   Подготовьте небольшой локальный скрипт для проверки относительных ссылок и подключите его в `package.json`, если это одобрят maintainers.

3. Улучшить критерии оценки заданий
   Добавьте краткие критерии оценивания для заданий на уровне виджетов в `docs/methodology.md`.

4. Сверить количество визуализаций
   Сравните README, лендинг и актуальные материалы дашборда, чтобы определить корректное число: 116 или 117.

5. Обновить уведомления о сторонних материалах
   Проверьте `assets/logos/` и скриншотные материалы, затем дополните `THIRD_PARTY_NOTICES.md` при необходимости.

6. Проверить двуязычную терминологию
   Убедитесь, что названия страниц, виджетов и заданий согласованы между README, методологией и файлами локализации.
