# Roadmap

This roadmap is intentionally practical. The repository is a landing and research-readiness layer for educational dashboard materials, not the full analytics platform.

## Completed foundation

- Static landing page for the MGIMO regional socio-economic dashboard.
- Bilingual EN/RU localization layer.
- Visual overview assets and dashboard navigation scenarios.
- Widget and assignment descriptions embedded in the landing page.
- Local Playwright i18n checks.
- Stage 7 research-readiness documentation, license matrix and contribution layer.

## Near-term priorities

- Reconcile the 116/117 visualization count against the latest dashboard workbook and document the source of truth.
- Fill current `DASHBOARD_URL` and `REPO_URL` placeholders when stable public targets are available.
- Add a small automated Markdown link/image existence check to the test suite.
- Expand the indicator dictionary references in methodology docs when the source dictionary is available.
- Keep screenshots synchronized with the current dashboard state.

## Methodology priorities

- Add a compact rubric for widget-level and integrative assignments.
- Document a repeatable workflow for exporting or validating the widget catalog.
- Add examples of acceptable analytical conclusions and common overclaims.
- Record known data-coverage caveats by thematic page.

## Contribution priorities

- Convert the starter issue list into GitHub issues after maintainers review it.
- Add issue labels for `methodology`, `i18n`, `content`, `third-party`, `good first issue` and `research-readiness`.
- Maintain bilingual docs with English first, Russian second, unless a file is explicitly Russian-only.

## Русский

Этот roadmap намеренно прикладной. Репозиторий является лендингом и слоем исследовательской готовности для учебных материалов дашборда, а не полной аналитической платформой.

Ближайшие приоритеты: сверить число визуализаций 116/117 с актуальным воркбуком, заполнить `DASHBOARD_URL` и `REPO_URL` при наличии стабильных публичных ссылок, добавить автоматическую проверку Markdown-ссылок и изображений, расширить методологию ссылками на словарь показателей и поддерживать скриншоты в актуальном состоянии.

Методические приоритеты: добавить краткую рубрику оценки заданий, описать воспроизводимый экспорт каталога виджетов, привести примеры корректных выводов и типичных чрезмерных интерпретаций, а также зафиксировать ограничения покрытия данных по тематическим страницам.
